# Laufband-Fernbedienung (Test)

Web-Bluetooth-Testseite für ein Citysports Walking Pad (BLE-Name `MAXFREE…`, Service `FFE0`).
Zeigt den Live-Status und probiert Start-, Stopp- und Tempo-Befehle automatisch durch.

Auf dem iPhone in **Bluefy** öffnen (Safari kann kein Web Bluetooth).

Beim Testen niemand auf dem Band, Sicherheitsclip griffbereit.
